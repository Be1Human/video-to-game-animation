# 蒙皮与附件修复

W(v,j) 静态蒙皮、β_k(t) 动作层、g_j 重定向增益不同；glTF morph weights 也不是游戏动作层。固定动作比 W，固定绑定比 q。保存动作/rest/几何/拓扑/UV/保护区权重指纹，不同拓扑的权重不能仅凭骨名复制。

## 实际网格隔离

修改前指定区域 Ω、边 E、顶点 ID 与选择理由，中央躯干/肩背/袖子/硬附件分开，不事后挑有利区域。空间盒可能把贴近背部的袖子包括进来，须核对实际连通表面。

同一时刻保持根、躯干及其他骨，禁用指定肩臂局部旋转，实际求值 d_v=||x_full−x_disabled||。这是链依赖诊断，不是自然替代姿态，不能要求所有肩胛/腋下点为零。约束可能重新赋值，须确认禁用生效。

同时测 r_e=||x_i(t)−x_j(t)||/||x_i(rest)−x_j(rest)||，报告压缩、拉伸、P95/峰值、异常时刻和画面。按尺度排除极短边，保持区域/阈值一致。中央区改善不能遮住袖窿恶化，峰值变小也可能只是摊开为大面积拉伸。

`mesh_diagnostics.py` 仅分析明确输入的对应网格/区域，不自动选区或禁用骨。含拓扑变化的求值修改器不能直接套原顶点索引。

## 修订方法

错误跨部位影响转回合理骨，再沿真实相邻表面渐变；固定保护区/候选骨集合/边界。按坐标或旧权重阈值硬切可能制造袖窿梯度尖峰，图平滑也不能无限扩散。记录有限迭代、约束、残差。

ΣW 和影响数只统计参与该 Armature 变形的骨组；修正遮罩、衣物控制等辅助组保留。Bone Envelopes 或不用顶点组时按实际策略另查。运行影响骨数是导出契约，不能默默截为 4。

LBS x_v=ΣW_vj M_j B_j⁻¹x_rest；DQS 需归一化双四元数，是非线性的。自写 DQS 求值器先与 Blender 同姿态逐点比较，再用有限差分查梯度，不能用 LBS 近似声称验证了 DQS。

## 多姿势静态权重拟合（按角色实现）

固定动作，以 W 为变量：E(W)=Σ_pose,edge ρ(r_e;lower_e,upper_e)+λ_keepΣ||x(W)−x_baseline||²+λ_graphΣ_neighbor||W_i−W_j||²。

约束非负、和为 1、保护区不变、左右骨集合及影响数。允许骨掩码+softmax 可保证单纯形，再由求解器优化。边长上下界是项目参数，不是衣料物理标准；合理折叠不能全部抹平。训练姿势与验证分开，留出中间帧、全部动作、独立肩臂试姿；记录次数上限和收敛状态，不称全局最优。本包提供方法和诊断，不附自动优化器。

## 附件和写回

衣料变化后复查纽扣/徽章；保留附件旧权重不等于继续贴合。静止表面对应可用于转移绑定；硬组件共享混合保形，缝制布章可变形。间距与原始厚度对比，刚性边长、贴合和穿插分别测。

写回顶点组先收集索引，避免边移除边遍历造成旧权重残留。保存重开核对权重、辅助组、保护区与原动作/rest/UV。渲染全动作原速和局部最差帧，保留失败试修。
