# 动作量化指标与计算边界

## 数据与时间

按实际时间戳 t 计算，不用帧索引直接替代秒。等间隔样本时间步为 Δt；非等间隔使用对应时间差或记录重采样方法。降采样先抗混叠，升采样不会恢复缺失的真实运动。

不跨遮挡、断帧、动画切段或重置求导。差分边缘使用已说明的单侧估计或舍弃，避免把处理边缘算作缺陷。对比使用相同采样率、导数算法与滤波窗口；否则 jerk 尖峰不可直接比较。

## 位置与导数

对位置 p 或可靠的单轴标量角 θ，中心差分为：

```text
v[k] = (p[k+1] - p[k-1]) / (2Δt)
a[k] = (p[k+1] - 2p[k] + p[k-1]) / Δt²
```

jerk 是加速度的一阶时间导数。若采用递归中心差分，说明这一设置：它与直接二阶/三阶差分的响应不同，不得混作相同测量。

导数放大噪声。可以使用局部多项式拟合或合适滤波稳定估计，但必须保留原始曲线，记录窗口时长、阶数/截止频率、相位延迟。离线零相位滤波会在事件前后传播影响，需保护接触与碰撞边界；实时结果不能以离线滤波的无延迟表现替代。

分别报告分量和向量模长。角速度单位为 rad/s 或 °/s，必须统一；位置速度只有在标定后才用 m/s。像素轨迹写 px/s，按身体尺度归一化后写 body-length/s，不伪装成真实世界单位。

## 旋转

四元数归一化；若相邻样本点积为负，翻转后一四元数的符号以维持表示连续。q 与 -q 是同一旋转，不应计为姿态跳变。

声明乘法顺序与主动/被动旋转约定。在常见主动旋转约定下：

```text
Δq_local = inverse(q[k]) * q[k+1]
Δq_world = q[k+1] * inverse(q[k])
```

将相对旋转转换为最短轴角旋转向量 r，区间角速度约为 r/Δt。求角加速度前将向量表达在同一坐标基中，不能直接相减不同随体坐标下的分量。相邻真实旋转超过 180° 时最短弧会丢失旋转圈数，需要更高采样率或额外旋转信息。

不要对四元数四个分量分别做普通曲线平滑。使用旋转空间的方法并保持单位长度；SLERP 只解决段内旋转插值，不保证所有关键帧衔接处角速度连续。单轴欧拉角可解缠用于展示，复杂旋转不靠欧拉角差分判断异常。

## 平滑指标

候选指标包括速度/加速度峰值、jerk 的 RMS、超阈值持续时长、已指定频带的抖动能量。不要仅用一个全片最大值决定质量；给出异常所在时间段并复核动作事件。

跨尺度、跨时长比较时，可使用声明过的无量纲积分平方 jerk：

```text
J = (T^5 / A^2) * integral_0^T ||d³p/dt³||² dt
```

这里 T 是同一语义动作段的时长，A 是预先选定且非零的位移幅度尺度。对往返动作不得直接用零净位移作 A；可选已说明的轨迹范围或骨架长度，但不同 A 定义的结果不可混比。静止/极小幅动作不强行计算归一化分数。这个指标描述平滑性，不是自然度，也不作为通用合格阈值。

频域/时频分析仅在振荡或抖动定位需要时使用。注明采样率、窗口和频带；最高可解释频率受采样率限制。不得把高频运动全部标为噪声。

## 接触与循环

接触最好来自动画标记或可靠碰撞/支撑信息。用高度和速度推断时声明地面、阈值、置信度与迟滞策略。高度低且速度小只支持接触候选，不能反过来把快速滑动样本全部排除，导致滑步漏报。

在接触面的局部坐标中计算接触点水平路径长度、最大偏移、速度和穿透深度。区分脚掌滚动、脚跟/脚尖切换与整脚非预期平移。根骨或脚踝位置不能自动等同实际接触点。

循环检查至少比较局部姿态差、线/角速度差和接触相位。root 的世界位移应先扣除预期周期平移/旋转；原地循环和向前行走循环不能用相同的位置归零规则。标明末帧是否重复首帧以及实际周期，避免一个采样间隔的误判。

## 协同与参考

分析肩→肘→腕等链条时，可比较事件附近的峰值时间差或局部互相关。周期信号、多个峰值、对称动作会产生歧义；峰值顺序不证明生物力学因果。把参考动作、语义阶段和可见运动一起用于判断。

参考必须在动作目的、风格、接触模式和骨架尺度上具有可比性。允许做相位对齐来比较姿态，但保留原始时间对照，不能用时间扭曲把节奏缺陷隐藏掉。

## 示例：柔和抬手 90°

仅适用于固定转轴、1 秒内完成的演示，不是动作质量的统一模板。t≤0 时静止于 0°，t≥1 时静止于 90°；0<t<1：

```text
匀速：θ(t) = 90t
柔和：θ(t) = 90(10t³ - 15t⁴ + 6t⁵)
```

柔和曲线两端速度与加速度为零；它的 jerk 与静止段衔接时仍可能不连续，不能称为所有阶导数连续。相同总时长下，中段峰值速度高于匀速动作，必须检查是否合乎意图。

匀速曲线接静止段时速度不连续，理论加速度含冲击项；采样差分显示的有限尖峰高度依赖采样率与算法，不是唯一物理加速度。不能据此规定所有动画采用某个固定加速度上限。

## 行为自查案例

- 只有三视图：请求时间输入，不输出流畅度分数。
- 静止四元数在 q 与 -q 间交替：修正表示连续性后应无旋转跳变。
- 合理挥拳命中出现 jerk 峰值：结合事件复核，不能自动平滑掉命中力度。
- 曲线平滑但支撑脚在地面移动：平滑性改善不能覆盖接触缺陷。
- 前进步行循环根位移非零：按周期根变换对齐后检查，不判定为必然跳变。
- 动画从 30 Hz 重采样至 120 Hz：不得声称新增了真实运动细节，也不直接比较原始导数峰值。
- 镜头平移造成视频全身轨迹同步变化：未去除相机影响前不能归咎于每个关节。
- 卡通定格/刻意匀速动作：依据风格目标评价，不把柔和曲线当作必选修复。
