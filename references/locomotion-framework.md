# 步态、方向与融合的统一评审框架

## 1. 状态与可观测量

用 x(t) = (G(t), {q_j(t)}, φ(t), {c_f(t)}, u(t)) 描述角色：

- G=(R,r)∈SE(3)：根朝向与位置；q_j∈SO(3)：关节局部旋转。
- φ∈S¹：步态相位，先指定左/右触地事件对应的相位；不能将动画百分比直接当作同一相位。
- c_f：脚跟/前掌的接触标签或置信度；区分人工、物理、推断。
- u=(v, ψ, ψ̇)：平面速度、身体朝向、转向速度。侧移角 β=wrap(atan2(v_x,-v_y)-ψ)，本式用于 Z 上、-Y 前向。

相机跟随视频通常不能唯一恢复 G。身体旋转不等于相机旋转；逐帧消除肩部朝向可能删除真实的骨盆/胸腔扭转。无法确定的根轨迹保留未知，另给明确标为设计的预览路径。

## 2. 五个互不替代的检查层

1. **有效性**：时间递增、数值有限、骨长、单位旋转、比例、权重、约束求值。通过仅代表数据可用。
2. **连续性**：位置速度/加速度/jerk 与 SO(3) 角速度；定位非预期尖峰，不抹掉落地等事件。
3. **任务约束**：接触、落脚点、离地间隙、动作结束状态、循环与转向目标。平滑不能覆盖违约。
4. **协调与意图**：同相位参考下的骨盆/胸腔相对扭转、对侧臂腿配合、头部稳定、腕部轨迹、偏走角。参考是条件，不是唯一人体模板。
5. **常速观感**：同步正/侧视角、真实时长、转弯与切换视频。机械感不能由一个标量最终决定。

状态采用“需修正/待复核/通过（限定范围）/无法判断”。不平均成自然度分数。

## 3. 旋转空间与导数

采用主动旋转、Hamilton 四元数 wxyz，单位化并消除相邻符号翻转。

ω_world[k+1/2] = Log(q[k+1] q[k]⁻¹) / Δt。

这里 Log 返回轴角旋转向量，不是半角；所有向量都在固定世界基底，再求差分。局部 q 的同式结果在父骨局部坐标，父骨转动时不可称为世界角加速度。必须使用求值后的世界旋转或显式搬运坐标基。

采样只能检验采样尺度上的连续性。30/60 Hz 烘焙的线性四元数关键帧不自动具有解析 C¹/C² 性质。高频噪声、有限差分和子帧插值须分别记录。

位置指标见 metrics.md。建议同时报告 RMS jerk、维度归一化 J、95 分位角加速度以及事件定位；不能只选改善最大的数字。比较时保留未滤波轨迹，统一采样和差分，改变时长另作相位对齐对照。

## 4. 接触与可控方向

接触点 p_f^S = (G_surface)⁻¹ G_root FK(q,f)。可信接触区间 I 内：

- 滑移路径 L_f = Σ ||Δp_xy||；最大偏离 D_f=max||p_xy-p_xy(t_start)||。
- 穿透 d_f=max(0, h_ground-p_z)，同时报告最大离地误差。
- 滚动接触应切换脚跟/前掌点；不能强迫整鞋同时锁死。

原地动画必须先指定虚拟根速度或跑台速度才谈地面滑移。用低高度推断接触时不可再用“速度小”排除滑动帧。阶段切换使用迟滞；每一段记录置信度和边界。

转弯不是把整个人绕 Z 轴转一下：需要根路径、落脚方向、骨盆/胸腔朝向和支撑期的联合处理。单纯整体旋转只能称方向预览；没有侧向落脚及接触修正，不能称合格的侧移动作。

可采用有参考约束的优化形式（本框架不声称已实现求解器）：

E = λ_data Σ c_j d_SO3(q_j,q̂_j)² + λ_ref Σ d_SO3(q_j,q_ref,j(φ,u))²
  + λ_vel Σ ||D_t Log(q)||² + λ_acc Σ ||D_t² Log(q)||²
  + λ_contact Σ c_f ||p_f^S-a_f||² + λ_task E_task。

λ 必须按单位/尺度归一化并记录；不能用大平滑权重掩盖接触或关键姿态。信任视频数据的程度由可见性和一致性决定；低置信深度可向参考收缩，但输出须标注参考辅助修正。骨长保持固定，关节活动域按角色约束；不是逐关节独立剪角。

## 5. 步态相位与协调

从接触事件定义连续相位并记录左右脚映射。匹配 φ_A=φ_B 后再混合走/跑。相同播放百分比可能分别处于左/右支撑，直接混合会抵消摆腿。

对骨盆、胸腔、上臂和大腿，画相位曲线及末端轨迹；计算相关/互相关只作为辅助。周期性造成多峰歧义，相位偏移不等于因果延迟。手腕方向跳变也可能来自错误 twist 或 A/T 姿校准，不能只平滑手的位置。

参考误差可用 d_SO3(q,q_ref)=||Log(q_ref⁻¹q)||；须同一骨架、同一局部轴、相位、速度和动作意图。合理的风格差异不能自动记为错误。

## 6. 循环边界与动作融合

先除去预期周期根变换 ΔG，再比较首末姿态、速度、角速度及接触相位。区分重复端点与无重复端点，并使用真实周期 T。

平移混合 p=(1-w)p_A+w p_B：

v=(1-w)v_A+w v_B+w′(p_B-p_A)

a=(1-w)a_A+w a_B+2w′(v_B-v_A)+w″(p_B-p_A)。

所以看起来平缓的权重也可能在姿态差大时产生明显加速。旋转用 SLERP/Log-Exp 或适当样条，不独立平滑四元数分量。五次 smoothstep w=10s³-15s⁴+6s⁵ 让权重两端一二阶导数为零，但只有两端源曲线本身兼容时才保证组合的对应连续性；它不保证接触。

惯性化思路：在切换时保留姿态差 x₀ 与速度差 v₀，按临界阻尼偏移 x(t)=[x₀+(v₀+ωx₀)t]e^(−ωt) 衰减，输出新目标+偏移。旋转在一致切空间中处理；大旋转、接触和关节限制要额外求解。半衰期/ω 是设计参数，不是人体常数。

### 烘焙循环的边界切线修正（可选）

重复端点 q₀=qₙ，间隔 h。在 q₀ 的一致局部切空间，取 r=[Log(q₀⁻¹q₁)−Log(q₀⁻¹qₙ₋₁)]/2，再设 q₁=q₀Exp(r)、qₙ₋₁=q₀Exp(−r)。位置取 d=(p₁−pₙ₋₁)/2，设 p₁=p₀+d、pₙ₋₁=p₀−d。在单位化线性四元数插值且同一符号分支下，两端边界切线相同。需要逐关节局部旋转和根位置一起处理；父链与驱动还要重新求值。

这是边界一阶修正，不保证其他关键帧或加速度连续，也可能改变接触；记录改动最大角度/位置，重新检查落地。30 Hz 边缘差分跨越多个关键帧时不能代表真正的单侧边界导数，可补充更短子帧间隔求值。计算小角度 Log 应使用 2 atan2(||q_xyz||, q_w)，避免 acos(q_w) 的浮点消减。子帧检查不增加动捕信息。

## 7. 可执行数据接口

`scripts/analyze_motion.py` 接受 JSON：

```json
{
  "name":"Walk", "time_s":[0,0.033333,0.066667],
  "units":"m", "axes":"Z-up, -Y-forward",
  "positions":{"hand.L":[[0,0,0],[0,0,0],[0,0,0]]},
  "world_quaternions":{"hand.L":[[1,0,0,0],[1,0,0,0],[1,0,0,0]]},
  "scale_m":1.72,
  "loop":{"duplicate_endpoint":true,"period_s":1.2},
  "contacts":[],
  "provenance":{"evaluation":"Blender evaluated FK+drivers","filter":"none"}
}
```

脚本依赖 Python 3 + NumPy ≥ 2，当前可执行接口仅接收米制数据；未标定视频应先按其他流程分析，不能冒充米。完整计算要求至少 9 个等间隔样本；例子仅说明字段，不足以算 jerk。positions/quaternions 是同一空间下已求值的世界数据。循环若有根位移/旋转，应在输入前转换到周期规范空间，记录变换；脚滑必须另给地面空间的真实接触点，不能复用规范空间数据。

```sh
python3 scripts/analyze_motion.py input.json --output report.json
python3 scripts/test_analyze_motion.py
```

脚滑计算仅在 contacts 提供 point、start_s、end_s、evidence、surface_stationary=true 且 point 位于地面世界坐标时启用。没有标签返回“未评估”。脚本不导入动画，不进行自动接触分类，不给合格阈值；高 jerk 候选必须回看。

## 8. 依据与边界

- Holden / Komura / Saito，SIGGRAPH 2017，[Phase-Functioned Neural Networks](https://theorangeduck.com/page/phase-functioned-neural-networks-character-control)：支持相位作为运动控制条件的依据；使用相位思想不等于实现或训练了 PFNN。
- Kovar / Schreiner / Gleicher，SCA 2002，[Footskate Cleanup](https://research.cs.wisc.edu/graphics/Gallery/FootskateSolver/)：接触约束、IK 与过渡连续性需一起处理；本技能没有复制其求解器。
- Daniel Holden，[Spring Roll Call](https://theorangeduck.com/page/spring-roll-call)：阻尼与惯性化的实现参考；数学平滑不能代替动作审阅。

交付需要方法、原始/修正数据、实际命令、曲线、正常速度回放、未通过项。不能用“数学理论完整”替代修复实际输入。

## 9. 同骨架开源参考与三类“权重”

先区分三个不同量：静态蒙皮权重 W(v,j) 决定顶点受骨骼的影响；动作融合权重 β_k(t) 决定动作层随时间的占比；重定向增益 g_j 用于缩小旋转或位移幅度。glTF 骨骼动作轨道不是作者的游戏融合树，名为 weights 的 glTF 动画通道通常表示形态键权重，也不是动作层权重。没有源工程、状态机或 NLA 信息时，作者的融合策略应记为未知，不从关键帧数量反推。

一般写作 x_v(t)=Skin(W_v, rest, q(t))。LBS 特例为 Σ_j W(v,j) M_j(t) B_j⁻¹ x_v；DQS 包含双四元数归一化，不能用这条线性公式直接当其实现。W 通常不随时间变，但会放大、传播或掩盖 q(t) 的问题。

做两种不同实验：

1. **固定绑定比较动作**：同一目标骨架层级、骨长、rest matrices、网格、W 和蒙皮算法，切换实际求值的动作 q_A/q_B。保存这些静态数据的哈希，另记录重定向映射、轴校准、单位、缺失骨、根路径处理、滤波、IK 与衣物驱动。来源没有原生同名骨架时，明确称“统一骨架重定向对照”，不是原生同骨架动作。
2. **固定动作比较绑定**：同一 q(t) 下比较 W_A/W_B 或蒙皮算法，用规定的肩、肘、膝、腕弯曲和扭转检查塌陷、拉伸、截面与穿插。异拓扑的原始角色仅能提供权重设计参考；未经空间/表面对应与复验不能直接复制顶点权重。

描述性检查包含未绑定顶点、ΣW 偏差、影响骨数、跨肢体影响、关节附近权重分布。最大影响骨数取决于导出和运行约束；更多骨、更平均、更宽过渡不自动更好。鞋底、扣件、护甲等刚性区域可能应硬绑定。关节球内无顶点时返回缺失数据；低多边形模型可补充沿骨轴的带状区域，固定相对骨长宽度并记录样本数、选择条件。报告分布图和局部视觉证据，不能把不同拓扑的比例直接排名。

动作比较并列保留原速回放与相位图。优先按可信触地事件对齐；没有事件时可以用同侧大腿前摆峰值作粗略相位锚点，明确它不等于触地。对齐后可观察同目标骨架下的关节 ROM、局部手腕旋转、骨盆/胸腔相对姿态、对侧臂腿相关与峰值时差。相关系数接近 1 也可能机械，跑动、持物与侧移不要求相同相关符号。不同时间长度的物理导数要保留实际秒，另报归一化相位/尺度指标；不得通过任意时间扭曲隐藏节奏问题。

循环的相位姿态差可写作 E_q(δ)=Σ_j λ_j ∫ ||Log(q_A,j(φ)⁻¹ q_B,j(φ+δ))||² dφ。λ 是分析关注度，不是蒙皮权重；这是参考相似度，不是自然度。不同运动意图、风格或接触状态不能混入同一参考分布。只有少数库时不得宣称建立了人类步态统计标准。

来源记录作者、原始许可、URL、文件哈希和原生动作名称；重定向后另存候选，不覆盖源文件。若当前修订已经从库 A 派生，与 A 对照只能解释改动；独立库 B 可以补充证据，但卡通比例、武器姿态、鞋型与缺失骨仍是混杂因素。保留源角色动作工程以区分源动作特征与重定向缺陷。

### 网格被其他肢体带走时：补做形变隔离

骨骼轨迹流畅、骨长固定、ΣW=1 不能证明衣服或皮肤变形正常。出现摆臂拉背、腿带裙腰等问题时，应增加受影响部位的正面、侧面和背面近景，检查实际求值后的网格，而不只看骨骼。

先在静止网格上指定区域 Ω 和边集合 E，保存顶点 ID，修改前后保持同一取样范围。在同一动作时刻固定根与躯干，分别将目标肢体局部旋转置回静止值，求 d_v(t)=||x_full,v(t)−x_disabled,v(t)||。这测量对该运动链的依赖，不是物理真实动作，也不能要求所有肩胛 / 腋下点都为零。骨骼链含父子传递时注明禁用范围；不能将世界背部位移全部归因于手臂。

同时记录边长比 r_e(t)=||x_i(t)−x_j(t)||/||x_i(0_rest)−x_j(0_rest)||、异常时刻及形变画面。按项目尺度排除极短边的数值放大，报告 P95 与峰值；拉伸比不是自然度总分。中央躯干、肩背过渡、袖子和刚性附件分区，预先定义的中央区改善不能掩盖袖窿新拉伸。阈值、影响骨数和约束参数属于项目选择，不冒充人体或行业标准。

修正优先分离错误的跨部位权重，并沿真实连通网格建立过渡；仅按空间盒或旧权重阈值切断，可能误伤贴近躯干的袖子或产生梯度尖峰。固定动作做前后对照，另做独立摆臂 / 抬臂试姿，核对动作、rest、几何 / UV 与受保护区域哈希。使用权重松弛或形变校正时记录迭代、约束、残差与新增运行依赖；不能只报告改好的区域或抹掉失败试修。

Blender 顶点组还可能是修正遮罩、衣物控制区或其他辅助数据。ΣW 与影响骨数只统计实际变形骨对应的组，辅助组保持原值，不参与蒙皮归一化或扩散；否则会误报权重和，也可能改变其他修改器的作用范围。

### 多姿势下联合拟合静态权重

若只按静止坐标或邻接平滑仍在袖窿产生尖锐过渡，可固定 q(t) 对静态 W 联合拟合多姿势形变，目标包含边长上下界惩罚、位置保持与邻接权重连续性；约束 W≥0、ΣW=1、受保护区域不变和项目影响骨数上限。DQS 是非线性的，自己的求值器必须先与 Blender 同姿态实际网格逐点核对，并用有限差分验证解析梯度；不能用 LBS 的线性近似直接声称 DQS 已通过。训练姿势与完整时间轴验证分开，保留未参与拟合的中间帧、独立肩关节试姿与失败迭代，达到次数上限时明确记录，不称全局最优。

衣料修改后须复核纽扣、徽章等附件与衣料的相对位置；仅保持附件原权重并不能保证继续贴合。可用静止表面对应传递绑定，硬附件组件共用一个混合以保持形状，缝制布章随表面变化。距离要与原始静止厚度比较，厚徽章的非零间距不自动是悬浮；刚性边长、逐帧贴合与穿插须分别检查。写回 Blender 顶点组时先收集组索引再清除，最终重开核对实际权重矩阵与求解值，避免索引变化残留旧权重。
