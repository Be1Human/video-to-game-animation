# 角色动作质量评估

将“动作不自然”转化为具体时间段、关节、运动指标和可回看的证据。判断目标是符合动作意图、节奏和约束；平滑度不是自然度的替代指标。

## 输入与评估边界

- 优先读取实际输入。可用输入包括带动画的 GLB/glTF、FBX、BVH、Blend、引擎动画轨道、关节轨迹、视频和有明确帧序的精灵图。扩展名不证明文件包含骨骼、动画或可解析数据，先检查内容与可用导入工具。
- 只有静态角色图或无时间顺序的姿势图时，不能评价动作连续性。明确缺少时间数据并请求动画、视频或有序帧与帧时长；不从外观推测动作质量。
- 从输入和上下文确定动作类型、用途、风格、时长、时间戳/帧率、循环或一次性播放、root motion 或原地动作、预期接触与关键事件。只询问会改变结论且无法合理推断的信息；其余列为假设并继续可做的分析。
- 区分三个证据层：直接读取的动画数据；由视频估计的轨迹；人工观察。不能将估计值标成精确测量值。
- 评审请求默认只读。修正建议不等于已经修改；用户要求修复时再按授权编辑并保留原始动画与可比较副本。

## 执行方式

### 先确认数据足以支持判断

- 骨骼输入记录骨架映射、单位、坐标系、根节点、采样时间和分析区间。分析实际求值后的姿态，注明是否包含 IK、约束、重定向、动画混合与引擎运行效果；无法执行的部分标为未验证。
- 视频输入先检查镜头运动、遮挡、变速、插帧和身份切换。保留姿态估计置信度，低置信和遮挡区间不跨段强插值；无法消除相机运动时，只报告可支持的相对运动。没有标定不得报告真实米制速度、真实力或精确三维关节角。
- 原地跑步需要根运动或跑台参考才能判断相对地面的足部滑动。先区分播放方式错误、捕获丢帧与动画数据本身的不连续。
- 重采样、去噪与差分的设置必须可追溯。保留原始曲线；演示数据与真实测量分开，不以示例结果替代输入分析。

### 联合检查曲线与动作

执行数值计算、设置阈值或生成修正曲线前，读取 [量化指标与计算边界](metrics.md)。根据动作选取相关维度，不强制所有动作都做同一套检查。

| 维度 | 检查内容 | 重要判断边界 |
| --- | --- | --- |
| 连续性与抖动 | 位置/旋转跳变，速度、加速度、jerk 的异常区间 | 先排除采样噪声、欧拉角跨界、四元数符号翻转；撞击、落地、刻意停顿不自动算错 |
| 启停与节奏 | 匀速段、缓入缓出、反复归零、预备与收势时间 | 曲线光滑仍可能节奏僵硬；不能给所有关键帧统一添加缓入缓出 |
| 肢体协同 | 骨盆/躯干/肩/肘/腕的带动顺序、峰值时差、末端跟随 | 结合动作参考和意图；全身同步在部分动作中合理，不靠随机延迟制造自然感 |
| 支撑与接触 | 支撑区间的脚/手相对接触面位移、离地、穿地、接触切换 | 需要可信接触标签或明确标注的推断；移动平台按接触面坐标分析 |
| 轨迹与姿态 | 手脚弧线、关节限制、骨长、穿插、root 与肢体协调 | 关节范围来自骨架/项目约束；不把骨盆当作已测质心，不对所有风格套人体物理规则 |
| 循环与衔接 | 接缝处姿态、速度、角速度和接触相位 | 位移动作按预期周期根位移/朝向比较，不要求世界位置回到原点 |

优先用动作播放与时间轴同步查看异常；首轮可选根节点/骨盆、头、双手和双脚，再下钻到异常链上的关节。轨迹问题应联合局部旋转与世界位置判断，避免把父节点运动误归因给子关节。

## 步态、偏走、转向与动作融合

涉及走跑、上半身摇晃、手脚不同步、转向或多动作融合时，读取 [步态与融合数学框架](locomotion-framework.md)。将根路径、身体朝向、步态相位和接触分开建模；不要逐帧删除方向后再用整段平滑冒充自然步态。需要复现量化时，使用其中的数据接口和 `../scripts/analyze_motion.py`，保存原始求值数据与报告。

比较开源动作或“动作权重”时，按该框架第 9 节做控制变量：区分静态蒙皮权重、随时间变化的动作融合权重与重定向幅度增益。固定目标骨架、rest pose、网格、蒙皮算法和权重后比较动作；源角色的权重另看，不把不同拓扑的共享权重比例当作质量排名。已有修订所依赖的库不是独立验证；需要独立来源时说明风格和重定向带来的混杂因素。

## 质量结论与证据

不使用通用毫秒阈值、固定 jerk 上限或凭感觉的 0–100 分。阈值优先来自项目验收标准，其次是同类已接受参考动作；统计离群只能提示复核。自定探索阈值要记录依据，不冒充行业标准。

每项发现至少包含：

| 字段 | 内容 |
| --- | --- |
| 定位 | 动画名、起止时间（秒），帧索引及帧率仅在已知时给出 |
| 对象 | 关节/运动链/接触点；局部、世界或接触面坐标 |
| 现象与影响 | 可见表现、对玩法或观感的影响 |
| 证据 | 曲线、回放时间点、原始数值与单位、采样/滤波设置 |
| 判断 | 已确认问题 / 待复核候选 / 符合动作意图；严重程度与依据 |
| 置信与原因 | 数据可信程度、根因是否已证实、仍缺少的证据 |
| 建议与验收 | 要修改的轨迹/时间段/约束，以及怎样确认改善且没有破坏原动作 |

严重程度按影响划分：高——破坏明确接触/命中/循环要求，或出现严重跳变、穿插；中——常速可见的非预期抖动、机械启停或节奏问题；低——不破坏功能的细节润色。置信度与严重程度分开记录，不能用“大尖峰”直接推导高严重程度。

总体结论使用：

- **通过（限定范围）**：所需证据与约定检查齐备，未发现违反约定标准的问题。说明已检查范围。
- **需修正**：存在已确认、与动作意图不符且影响使用的缺陷；列出优先修正项。
- **待复核**：存在影响结论的候选问题或缺少基准，不能确认通过/不通过。
- **无法判断**：缺少时间数据或数据质量不足以完成目标判断。

某一维度无证据时明确“未评估/不适用”；整体平均不能掩盖关键缺陷。用户明确要求打分时，先说明维度、权重、锚点与缺失项处理，给出可审计的项目评分，不称其为客观自然度分数。

## 修正与复验

- 非预期高频抖动：先确认来源，再局部去噪；禁止直接对整段强低通并宣布质量提升。
- 机械启停：调整关键帧时间和切线，必要时使用保持端点条件的曲线；核对中段峰值速度、幅度与关键事件是否仍合适。
- 肢体僵硬：按参考调整带动顺序、跟随与收势。没有参考时提出可对比候选，不断言固定延迟最自然。
- 足部滑动：根据可靠接触区间联合调整足部 IK、根轨迹和接触过渡，检查膝部弹跳及新增穿插。
- 循环/切换突变：匹配接缝姿态与速度，结合接触相位和 root motion；需要时采用过渡混合或惯性化，不能只复制首帧到末帧。
- 修正后使用同一时间基准、坐标系、采样与预处理设置对照；改时长时另报真实时长，并用事件/相位对齐比较节奏。
- 复验既看数值也看常速播放。确认关键姿态、命中时刻、接触和风格保留，防止出现迟滞、动作变软、过冲与滑步。

## 交付

先给结论、最重要的证据和优先修正项。按需给出同步回放、角度/速度/加速度曲线、接触时间条或关节×时间异常图，不为凑图展示所有骨骼。标注示例、估计或实测及单位。

即时评审可直接在聊天中交付。用户需要独立报告时使用自包含 HTML，记录状态、日期、输入、范围、方法、发现、未验证项和复验结果，并遵守目标项目的归档规则。技能自身的 SKILL.md 和计算参考是可执行指令资源，不作为项目报告替代品。

若未处理实际动画，最终只能称技能、方案或演示已完成；不能声称角色动作已经验收或已修复。本技能提供评估流程、数学框架与已求值轨迹的分析脚本；不内置动画导入器、姿态估计模型或一键自然度评分程序。
