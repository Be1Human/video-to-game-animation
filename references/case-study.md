# 案例：裙装角色的视频动作修订

以下源自一次实际制作迭代，数值不是通用参数，阶段结果不等于整体最终验收。本仓库不附原角色、视频、贴图和动作库。

| 阶段 | 问题 | 决策 |
| --- | --- | --- |
| 单目估计 | 跟随镜头、NPC 切换、遮挡深度不稳定 | 裁剪重跑，保留置信/缺失，根路径和细手指不冒充已捕获 |
| 重定向 | 腕翻转、腿裙互拉 | 分查 A/T rest、骨轴、不可观测 twist、拓扑和蒙皮，不只平滑曲线 |
| 协调 | 步态与身体摇晃、启停机械 | 参考辅助相位重建，SO(3) 周期拟合与启停混合，鞋底高度 IK 单独处理 |
| 参考对照 | 派生动作只对原库容易自证 | 同目标骨架/绑定对照独立库；原角色权重另看，缺游戏融合树则写未知 |
| 摆臂带背 | 肩臂权重扩到中央背部 | 固定动作禁用肩臂，检查实际网格依赖和边长比 |
| 初次局部修复 | 背稳定但袖窿更拉 | 拒绝仅凭中央指标宣布完成，按真实连通表面过渡并保护辅助遮罩 |
| 后续肩部工作 | 静态平滑难兼顾多姿势，衣料改动暴露附件间隙 | 多姿势静态权重目标、DQS 实际校验、留出帧、附件贴合复查；后续独立修订另行验收 |

一轮跑停测量：预先定义的 122 个中央背部点，其肩臂隔离最大差从 23.785 mm 降至 5.500 mm；同时含袖窿区域最大边长比从 1.972 增至 2.174。局部改善不能替代整体验收。

该阶段共 13 动作，每版 827 求值时刻，跑停含 193 整帧/半帧采样，另有 5 个独立肩臂试姿。动作/rest/静止几何/UV 指纹一致。此数量只是案例规模，不是技能固定预算。

当时高度 IK 未实现水平足锁，偏走/转向仍是设计预览，最终动作含参考辅助重建。数学降噪、无 NaN、文件重开、渲染成功均不等于全身自然度、衣物碰撞或游戏正式验收。
